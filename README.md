# Design Web -- World University

## Deskripsi

Tugas Design Web ini merupakan perancangan UI/UX website **World
University**. Desain dibuat menggunakan Figma melalui dua tahap, yaitu
wireframe sebagai rancangan struktur halaman dan high-fidelity mockup
sebagai tampilan visual yang lebih detail.

## 1. Wireframe Desktop

Wireframe desktop digunakan untuk menyusun struktur halaman pada layar
komputer sebelum desain visual diterapkan.

Bagian utama: - Navigasi: Beranda, Tentang, Fasilitas, dan Kontak. -
Hero section dengan judul utama dan area gambar kampus. - Tentang
Program dengan tiga kartu bidang pembelajaran. - Fasilitas kampus dalam
tiga kolom. - Bagian penutup dengan tombol Hubungi Kami.

![Wireframe Desktop](WF_4525210067_SakaLaksmanaH.png)

## 2. High-Fidelity Mockup Desktop

Mockup desktop menampilkan desain yang lebih mendekati hasil akhir.
Desain menggunakan warna hijau tua, cokelat, dan putih, serta dilengkapi
gambar kampus, kartu informasi, dan tombol.

Bagian yang ditampilkan: - Hero dengan gambar kampus dan tombol aksi. -
Tiga bidang pembelajaran: Web Development, Software Development, dan
Data & Technology. - Tiga fasilitas: Ruang Kelas, Laboratorium, dan
Kelas Utama. - Bagian penutup dengan ajakan untuk menghubungi kampus.

![High-Fidelity Mockup
Desktop](high-Fidelity_Mockup_4525210067_SakaLaksmanaH.png)

## 3. Wireframe Mobile

Wireframe mobile merupakan rancangan struktur website untuk layar
ponsel. Susunan konten diubah menjadi satu kolom agar tetap rapi dan
mudah dibaca pada layar yang lebih kecil.

Penyesuaian utama: - Navigasi dibuat lebih ringkas. - Kartu bidang
pembelajaran dan fasilitas disusun vertikal. - Tombol dibuat lebar agar
lebih mudah ditekan.

![Wireframe Mobile](WF_Mobile_4525210067_SakaLaksmanaH.png)

## 4. High-Fidelity Mockup Mobile

Mockup mobile menerapkan tampilan visual pada versi ponsel dengan tetap
mempertahankan warna, tipografi, dan gaya desain desktop. Konten disusun
dari atas ke bawah, sehingga pengguna dapat membaca informasi dengan
nyaman tanpa perlu melihat susunan tiga kolom.

![High-Fidelity Mockup
Mobile](high-Fidelity_Mockup_Mobile_4525210067_SakaLaksmanaH.png)

## Kesimpulan

Perancangan dilakukan dalam empat tahap: wireframe desktop,
high-fidelity mockup desktop, wireframe mobile, dan high-fidelity mockup
mobile. Versi mobile menyesuaikan tata letak untuk layar kecil dengan
susunan satu kolom, kartu vertikal, dan tombol yang lebih lebar.
